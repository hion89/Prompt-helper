말결 개인정보처리방침

시행일: 2026년 10월 19일

말결은 사용자가 작성한 자연어 요청을 더 명확한 AI 프롬프트로 재작성하는 Chrome 확장 프로그램입니다. 기존 이름은 Prompt Optimizer이며, 동일한 확장 프로그램의 이름과 디자인을 변경했습니다. 본 방침은 확장 프로그램이 처리하는 정보와 그 사용 방식을 설명합니다.

1. 처리하는 정보

사용자가 입력한 요청

일부 명확한 기초 질문은 로컬 규칙으로 원문을 유지하며 Gemini API로 전송하지 않습니다. 재작성이 필요하거나 사용자가 강제 최적화를 선택하면 작성한 요청과 대상 AI, 응답 언어, 프롬프트 언어 및 최적화 모드가 Google Gemini API로 전송됩니다. Custom 모드에서는 선택한 콘셉트 또는 직접 작성한 최적화 지침도 함께 전송됩니다. 이 정보는 프롬프트 재작성 결과를 생성하는 데 사용됩니다.

Gemini API 키

사용자가 직접 제공한 Gemini API 키를 사용합니다. 기본 설정에서는 브라우저 세션 저장소에 보관되어 브라우저 종료 또는 확장 프로그램 재로드 시 삭제됩니다. 사용자가 영구 저장을 선택하면 해당 Chrome 프로필의 로컬 확장 저장소에 보관됩니다. API 키는 Chrome 동기화 저장소나 개발자 서버로 전송되지 않습니다.

설정과 임시 초안

대상 AI, 언어, 모드, 테마, 미니 도구 설정과 재사용하는 Custom 콘셉트·수동 최적화 지침은 Chrome 로컬 확장 저장소에 저장됩니다. 수동 지침은 AI 웹사이트와 오류 진단 보고서에 노출하지 않습니다. 팝업의 요청과 결과 초안은 Chrome 세션 저장소에만 임시 보관됩니다.

지원 사이트의 입력창 내용

ChatGPT, Claude, Gemini에서 사용자가 가져오기, 최적화, 교체 또는 복구 기능을 직접 실행할 때 해당 입력창 내용을 처리합니다. 확장 프로그램은 메시지를 자동 전송하지 않습니다.

공개 모델 목록과 프로필

시작 또는 모델 목록 갱신 시 hion89.github.io/Prompt-helper/registry/의 공개 JSON을 읽습니다. 모델·프로필 데이터, 확인 시각과 이전 정상본을 Chrome 로컬 확장 저장소에 캐시합니다. 이 조회에는 프롬프트, 최적화 결과, Custom 지침, API 키를 포함하지 않으며 쿠키와 referrer를 보내지 않습니다. 일반적인 HTTPS 연결 과정에서 GitHub 호스팅 서비스가 접속 IP와 브라우저 요청 정보를 처리할 수 있습니다. 확장은 원격 JavaScript를 다운로드해 실행하지 않습니다.

오류 진단 정보

최근 오류 유형, 발생 시각, 확장 버전과 관련 기능 이름을 최대 7일, 30건까지 로컬에 저장할 수 있습니다. Gemini API 키, 프롬프트 원문, 최적화 결과와 전체 방문 주소는 진단 기록에서 제외하거나 마스킹합니다. 보고서는 사용자가 직접 복사하거나 이메일로 보낼 때만 개발자에게 전달됩니다.

답변 품질 평가

수동 비교는 입력한 프롬프트·답변·기준·근거를 로컬 메모리에서 처리합니다. Gemini 자동 평가를 계획 확인 후 별도로 동의하고 시작하면 원문·최적화문·공통 시스템 지침·평가 기준·참고 자료·생성 답변이 Google Gemini API로 전송됩니다. 등록된 Gemini 키는 신뢰할 수 있는 백그라운드에서만 읽습니다. 평가 자료·결과는 화면과 실행 중 백그라운드 메모리에만 유지하고, 호출 수·예약액 등 실행 메타데이터만 보호된 Chrome 세션 저장소에 기록합니다. 사용자는 중단하거나 실행 종료 후 평가 세션을 비울 수 있습니다. 보고서는 사용자가 직접 미리보기·저장하며 자동 업로드하지 않습니다. 기본 내보내기는 원문과 답변을 제외하고, 텍스트 포함은 별도로 선택합니다.

2. 정보 사용 목적

  • 자연어 요청 분석과 프롬프트 재작성
  • 지원 사이트 입력창 가져오기·교체·복구
  • 사용자 설정 유지
  • 오류 진단과 사용자가 요청한 기술 지원
  • 사용자가 직접 실행하는 성능 평가

3. 제3자 처리

프롬프트 최적화 요청은 사용자의 Gemini API 키를 이용해 HTTPS로 Google Gemini API에 직접 전송됩니다. Google의 정보 처리는 Google의 관련 약관과 개인정보처리방침의 적용을 받습니다. 프롬프트를 위한 개발자 소유 중계 서버를 사용하지 않습니다. 공개 Registry는 GitHub Pages가 호스팅합니다. 운영자가 모델 목록을 수집하거나 고정 시험으로 프로필을 평가하는 자동화는 확장 사용자의 원문·키와 분리되어 있으며 운영자 소유 키와 합성 시험 데이터만 사용합니다.

4. 정보 판매와 광고

말결은 사용자 정보를 판매하지 않으며 맞춤 광고, 신용 평가 또는 사용자 추적에 사용하지 않습니다. 별도의 분석 서비스나 광고 SDK를 포함하지 않습니다.

5. 보관과 삭제

사용자는 API 설정에서 저장된 API 키를 삭제할 수 있습니다. 팝업의 Reset으로 현재 초안을 지울 수 있으며, Custom 수동 지침은 지침 입력칸을 비워 삭제할 수 있습니다. 확장 프로그램을 제거하면 Chrome이 해당 확장 프로그램의 로컬 및 세션 저장 데이터를 삭제합니다. 사용자가 기술 지원을 위해 이메일로 전달한 진단 보고서는 문제 해결에 필요한 기간만 보관합니다.

6. 보안

Gemini API 요청에는 HTTPS를 사용합니다. API 키는 콘텐츠 스크립트와 지원 웹사이트에 노출하지 않도록 신뢰할 수 있는 확장 프로그램 컨텍스트에서만 읽습니다. 다만 사용자가 영구 저장을 선택한 API 키는 운영체제의 별도 암호화 금고가 아닌 Chrome 확장 로컬 저장소에 보관됩니다.

7. 사용자의 선택

사용자는 언제든 API 키를 삭제하고 Gemini API 접근 권한을 철회하거나 확장 프로그램을 제거할 수 있습니다. 생성된 프롬프트는 적용 전에 확인할 수 있으며 메시지 전송 여부는 사용자가 결정합니다.

8. Chrome 웹 스토어 제한적 사용 준수

Google API에서 받은 정보의 사용은 Chrome 웹 스토어 사용자 데이터 정책과 제한적 사용(Limited Use) 요구사항을 준수합니다.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

선택적 사용자 프로필

배경정보, 전공·직업, 지식 수준, 설명 방식, 응답 언어, 스타일 및 관련 키워드는 모두 선택 사항이며 별도의 브라우저 로컬 저장소에 저장합니다. 적용 기본값은 OFF이며 OFF 상태에서는 프로필 내용을 외부 API로 전송하지 않습니다. ON 상태에서는 질문의 키워드와 작업 유형으로 선별한 후보 정보만 Google Gemini API로 보내 관련성에 따라 참고합니다. 현재 요청과 명시적인 설정이 우선합니다. 추가 분류 호출이나 자동 업로드는 없습니다.

API 설정의 나의 프로필에서 수정·적용 변경·전체 삭제할 수 있습니다. 프로필 원문을 웹페이지 Content Script나 오류 진단 보고서에 제공하지 않습니다. 최적화 결과에는 개인화된 표현이 포함될 수 있으며 사용자가 복사·교체하기 전에 검토할 수 있습니다. 자동 A/B 평가는 프로필을 사용하지 않습니다. 로컬 저장소는 암호화 금고가 아닙니다.
