주요 기능

  • Gemini 기반 의미 분석과 프롬프트 재작성
  • 네 가지 AI 서비스와 최적화 모드 지원
  • 결과 확인 후 복사 또는 입력창 교체
  • 입력창 연결 복구와 오류 진단

API와 비용

사용자가 직접 등록한 Gemini API 키를 사용합니다. 무료 또는 유료 여부와 호출 한도는 사용자의 Google API 프로젝트 설정에 따릅니다. 유료 등급이나 다른 모델로 자동 전환하지 않습니다.

데이터 처리

Optimize를 실행하면 작성한 요청과 선택 설정이 HTTPS를 통해 Google Gemini API로 전송됩니다. 개발자 소유 중계 서버와 광고·분석 SDK는 사용하지 않습니다.
