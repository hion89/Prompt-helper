확장 1.13.1에서 이미 공개됐던 로컬 프롬프트 구성 코드를 독립 실행 예제로 정리했습니다. 최신 확장·데스크톱 앱 전체 소스와는 구분됩니다.

어떻게 활용하나요?

Node.js 22 이상으로 아래 명령을 실행하세요. 의존성 설치·API 키·계정·브라우저 권한이 필요 없으며 엔진은 네트워크 요청을 보내지 않습니다.

git clone --depth 1 https://github.com/hion89/Prompt-helper.git
cd Prompt-helper/open-source/prompt-core
npm test
npm run example

원문 → 작업·언어 분류 → 모드 규칙 → 브랜드별 형식 → 언어 → 완성 텍스트 흐름을 확인하고 수정할 수 있습니다. 원본 회귀 테스트와 출처 해시, JavaScript 사용 예제를 함께 제공합니다.

사용 조건과 한계

참고 엔진 디렉터리는 MIT 라이선스로 수정·상업적 사용·재배포할 수 있습니다. 고지를 유지하세요. 로고·상표·다른 경로·제3자 자료·과거 전체 기록에는 이 허가가 자동 적용되지 않습니다.

원문에 지침을 덧붙이는 역사적 규칙 기반 예제입니다. 현재 Gemini 재작성, 최신 ECO 정책·Custom·개인화·원문 잠금·모델 탐색을 포함하지 않으며 실제 답변 품질·토큰 절감을 보장하지 않습니다.

Open-source reference

The offline prompt core is a self-contained JavaScript reference extracted from the already-public extension 1.13.1, not the full source of the current product. Run the commands above with Node.js 22+. No dependencies, credentials or API calls are needed.
