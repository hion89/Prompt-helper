# 말결 — AI 프롬프트 최적화

**내 뜻을 살리는 프롬프트.**

말결(Malgyeol)은 평소 쓰던 요청을 분석하고, 사용할 AI 모델에 맞는 프롬프트로 다듬는 Chrome 확장 프로그램입니다. 사용자가 직접 등록한 Gemini API 키로 실행하며 결과는 확인한 뒤 직접 적용합니다.

- [제품 소개](https://hion89.github.io/Prompt-helper/)
- [고객 지원](https://hion89.github.io/Prompt-helper/support.html)
- [개인정보처리방침](https://hion89.github.io/Prompt-helper/privacy-policy.html)

이 저장소에는 공개 문서, 브랜드 아이콘과 모델 목록 JSON, Pages 배포에 필요한 최소 검증 코드만 게시합니다. 개발 소스와 내부 자동화는 별도 비공개 저장소에서 관리합니다. 모델 목록을 내려받을 때 사용자 API 키나 작성한 요청을 이 저장소로 전송하지 않습니다.
