등록 상태를 확인하고 있습니다.

기본값은 세션 저장입니다. 영구 저장은 이 Chrome 프로필의 로컬 저장소를 사용하며 별도 암호화 금고는 아닙니다. 키는 사이트 입력창이나 동기화 저장소로 전달하지 않습니다.

등록 후 사용하기

  1. 확장 아이콘을 눌러 팝업을 엽니다.
  2. 대상 AI·응답 언어·모드를 고르고 Optimize를 누릅니다.
  3. 결과를 검토한 뒤 Copy 또는 Replace를 사용합니다.

키 등록·삭제는 생성 요청을 보내지 않습니다. Optimize를 누르면 원문과 선택 설정을 Gemini API에 보냅니다. API 응답은 사실·조건을 바꿀 수 있으므로 적용 전 확인하세요.

자동 재시도, 유료 등급 업그레이드, 다른 모델로의 자동 전환은 없습니다. 확장 프로그램은 키의 실제 과금 등급을 판별하거나 Google의 청구를 차단할 수 없습니다.
