# 변경 기록

## 1.13.1 — 2026-10-19

- 사용자가 제공한 한글 말결 로고를 원본 그대로 사용하고 아이콘 16·32·48·128px를 다시 만들었습니다.
- 딥 그린 헤더와 크림색 바탕으로 팝업, 설정·도움말·진단·평가 화면 및 공개 지원 페이지의 디자인을 통일했습니다.
- 이전 1.13.0 디자인과 제출 패키지를 제거하고 새 로고 중심의 홍보 이미지와 소개 화면, 스토어 ZIP을 재작성했습니다.
- 기존 설정·확장 ID 유지 경로·API 처리·권한에는 변경이 없습니다.

## 1.13.0 — 2026-10-19

- 앱 이름을 말결(Malgyeol)로 변경하고 스토어 표시명, 팝업, 설정, 도움말, 진단·평가 화면 및 공개 지원·개인정보 페이지를 맞췄습니다.
- 말의 결을 표현한 새 아이콘과 홍보 이미지, 1280×800 소개 화면 및 스토어 제출용 자료를 제공합니다.
- 기존 확장 항목의 API 키, 설정, 진단·벤치마크 파일 형식 및 모델 목록 URL을 유지합니다. 기능·권한·API 전송 경로는 변경하지 않았습니다.

## 1.12.0 — 2026-10-18

- 모델 목록을 동적 JSON Registry로 분리하고 제공사별 검색, NEW, 프로필 상태와 수동 갱신을 추가했습니다. OpenRouter를 통해 기타 제공사의 텍스트 모델을 확장할 수 있습니다.
- 현재/이전 정상 캐시, 번들 초기값, SHA-256·Schema·연결 검증과 버전 검사로 손상·오프라인·지원 종료 상황에서도 기존 동작을 유지합니다. 모델이 사라져도 사용자 선택 ID를 보존합니다.
- 하루 한 번 탐색하는 GitHub Actions, 공식 목록 API 어댑터, 명시적 별칭 정규화, 공개 문서 캐시, 제한된 LLM 후보 생성과 실제 평가 후 승격 파이프라인을 추가했습니다.
- 실제 비교 시험·보고서 해시 없는 후보를 활성화하지 않습니다. 원격 JSON은 제한된 설정 데이터이며 지시문 생성 코드와 기존 모드·정보 보존 규칙은 확장에 번들됩니다.
- 운영 자동화의 생성·평가 호출 및 비용 한도 기본값은 0입니다. 별도 운영 Secrets를 사용하고 확장 사용자의 키·프롬프트를 수집하지 않습니다.
- 공개 Registry 조회를 위한 GitHub Pages 호스트 접근 권한과 관련 개인정보 안내를 추가했습니다. 실제 모델별 품질 개선률을 검증했다는 의미는 아닙니다.

## 1.11.0 — 2026-10-18

- 대상 AI 브랜드를 고르면 해당 브랜드의 세부 모델만 표시합니다. 브랜드별 선택값을 보관하고, 알 수 없는 모델은 브랜드 공통 지침으로 처리합니다. Perplexity는 현재 대상과 자동 연결에서 제외합니다.
- 공식 OpenAI·Google·Anthropic 문서를 확인해 모델·계열별 재작성 지침을 실제 Gemini 요청에 적용합니다. GPT-4.1, 추론 계열, GPT-6, Gemini 계열과 Claude 버전별 지침의 출처와 확인일을 함께 제공합니다.
- 최적화 엔진 모델과 프롬프트를 사용할 대상 모델을 구분합니다. 모델 설정이 바뀌면 이전 결과와 진행 중인 오래된 결과를 적용하지 않습니다. Custom 지침과 함께 원문의 명시적인 요구를 우선합니다.
- 미니 도구에 `−` 아이콘 최소화, `✦` 클릭 복원과 아이콘 드래그를 추가했습니다. 최소화 상태를 저장하고 팝업에서도 펼칠 수 있습니다. 기존 `×` 완전 숨김도 유지합니다.
- 기존 API 스트리밍·모델 저장 수정도 포함합니다. 공개된 지침에 근거한 설계이며 실제 모델별 품질 향상률을 검증한 결과는 아닙니다.

## 1.10.2 — 2026-10-14

- 모델 저장을 신뢰된 확장 페이지의 백그라운드 메시지로 처리하고, 저장한 모델을 다시 읽어 확인합니다.
- 조회된 현재 모델도 다시 저장할 수 있도록 저장 버튼 조건을 변경했습니다.
- 저장 실패의 실제 원인과 업데이트 후 끊긴 설정 탭을 다시 여는 안내를 표시합니다.
- 키를 변경하거나 삭제하면 이전 키의 모델 목록을 다시 사용하지 않도록 초기화합니다.

1.10.1의 연결 시간 초과는 여전히 최초 서버 응답이 25초 안에 오지 않았다는 뜻입니다. 모델 선택·저장 경로를 검증한 수정이며 실제 Gemini 생성 성공을 확인한 배포는 아닙니다.

## 1.10.1 — 2026-10-14

- 모든 모드의 생성 요청이 25초 만에 중단되던 공통 API 경로를 스트리밍 응답 수신으로 변경했습니다. 최초 서버 응답은 25초, 요청 전체는 최대 90초까지 기다립니다.
- 긴 응답 수신 중 Chrome 서비스 워커가 유휴 종료되지 않도록 진행 중인 요청에만 생존 확인을 수행합니다.
- 연결 응답 지연과 최종 생성 지연을 모델명과 단계 코드로 구분합니다. 서버의 HTTP 408·504 오류도 별도로 안내합니다.
- 팝업과 페이지 미니 도구에 대기 경과 시간을 표시합니다.
- 정상 종료된 결과만 표시·적용하며 부분 응답, 중단된 응답과 내부 생각 토큰은 적용하지 않습니다. 자동 재시도·모델 변경은 수행하지 않습니다.

사용자의 실제 Gemini 생성 요청을 재현한 검증은 아닙니다. 기존 25초 클라이언트 중단 동작을 확인하고 지연·중단·분할 응답을 테스트로 검증한 수정입니다.

## 1.10.0 — 2026-10-13

- 최적화 전에 Gemini API 키 등록 상태와 서버 접근 권한을 확인할 수 있는 상태 카드를 추가했습니다. 키 미등록, 권한 필요, 사용 준비, 요청 중, 마지막 API 응답 성공·실패를 구분합니다.
- 키 또는 접근 권한이 없으면 Optimize를 비활성화합니다. 상태 확인 버튼은 Gemini 생성 요청을 보내지 않습니다.
- 수동 Custom 모드에서 최대 6,000자의 최적화 지침을 직접 작성하고 저장할 수 있습니다.
- 자동 Custom 모드에서 정확함, 절약, 자연스러움, 전문성, 친근함, 명료함, 구조화, 창의성, 상세함, 실용성 중 여러 콘셉트를 선택할 수 있습니다.
- Custom 설정은 이 브라우저에 저장되며 팝업과 페이지 미니 도구에서 함께 사용합니다. 수동 지침은 Custom에서만 Gemini API로 전송됩니다.
- 사용 설명서와 개인정보처리방침에 Custom 지침의 전송·저장·삭제 방법을 반영했습니다.

새 Chrome 권한은 추가하지 않았습니다. 기존 Gemini API 키와 모델 설정을 그대로 사용할 수 있습니다.

검증: 단위 테스트 40개, 브라우저 픽스처 검증 34개 및 Manifest·구문·리소스 검사 통과. 실제 API 호출과 로그인한 서비스 화면은 이번 검증에서 사용하지 않았습니다. 기존 1.9.0 벤치마크 수치는 해당 버전의 결과이며 1.10.0 성능 측정값이 아닙니다.
