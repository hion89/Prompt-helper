START

처음 시작하기

  1. Gemini API 키를 준비합니다.팝업에서 Gemini API 설정을 열고 Google AI Studio에서 발급한 키를 등록하세요.
  2. 사용할 모델을 확인합니다.사용 가능한 모델 조회를 누른 뒤 Flash 또는 Flash-Lite 모델을 선택하고 저장하세요.
  3. AI 페이지를 새로고침합니다.확장 프로그램을 처음 설치하거나 업데이트했다면 열려 있던 ChatGPT·Claude·Gemini·Perplexity 탭을 한 번 새로고침하세요.
  4. 평소처럼 요청을 작성합니다.확장 팝업에 직접 쓰거나 AI 페이지 입력창에 작성한 뒤 가져올 수 있습니다.
알아두세요. Gemini는 프롬프트를 재작성하는 엔진입니다. 대상 AI는 완성된 프롬프트를 사용할 ChatGPT·Claude·Gemini·Perplexity 중 하나를 뜻합니다.
BASIC

기본 사용법

1

요청 준비

팝업에 입력하거나 페이지에서 가져오기로 AI 입력창의 글을 불러옵니다.

2

설정 선택

대상 AI, 응답 언어, Default·ECO·Precision·Natural 모드를 선택합니다.

3

최적화

Optimize Prompt를 누르고 Gemini가 재작성한 결과를 확인합니다.

4

사용

Copy로 복사하거나 Replace로 연결된 입력창의 내용만 교체합니다.

Replace와 미니 도구의 Optimize는 메시지를 자동 전송하지 않습니다. 결과를 읽어 본 뒤 AI 사이트에서 직접 전송하세요.

MODES

어떤 모드를 선택할까요?

Default일반 질문, 요약, 글쓰기처럼 대부분의 요청에 사용합니다.
ECO핵심 조건을 유지하면서 짧은 프롬프트가 필요할 때 사용합니다.
Precision코드 분석, 오류 진단, 비교처럼 조건과 검증 기준이 중요할 때 사용합니다.
Natural메일, 게시글, 대화문처럼 자연스러운 표현이 중요할 때 사용합니다.
TOOLBAR

AI 입력창 옆 미니 도구

  • ✦ Optimize: 현재 입력창 내용을 최적화한 결과로 교체합니다.
  • ↶ Undo: 방금 교체한 내용을 원문으로 되돌립니다.
  • ⠿: 끌어서 원하는 위치로 옮깁니다. 더블클릭하면 입력창 옆 기본 위치로 돌아갑니다.
  • ×: 미니 도구를 숨깁니다. 다시 켜려면 확장 팝업의 페이지 미니 도구를 켜세요.
HELP

특정 상황에서는 이렇게 하세요

최적화 성능을 숫자로 비교하고 싶음

위쪽의 성능 평가를 열어 평가를 시작하세요. 고정 시험 요청 8개가 현재 Gemini 모델로 전송되며 완료율, 정보 보존율, 의도·언어 정확도, 응답시간과 토큰 사용량을 계산합니다. 결과 JSON을 저장하면 버전이나 모델을 바꾼 뒤 수치를 비교할 수 있습니다.

오류를 개발자에게 보내고 싶음

위쪽의 오류 진단 열기를 누르고 문제 설명과 재현 순서를 작성하세요. 보고서 복사 또는 JSON 파일로 저장을 사용한 뒤 dominicjjung@gmail.com으로 보내 주세요. API 키와 프롬프트 원문은 자동으로 포함하지 않습니다.

입력창 연결 안 됨 또는 입력창을 찾지 못함
  1. AI 페이지의 입력창을 한 번 클릭합니다.
  2. 팝업 아래의 ↻ 다시 찾기를 누릅니다.
  3. 계속 실패하면 페이지 새로고침을 누르고 페이지가 열린 뒤 팝업을 다시 엽니다.
  4. 확장 프로그램을 막 업데이트했다면 모든 AI 페이지를 새로고침하세요.
미니 도구가 보이지 않음

팝업에서 페이지 미니 도구가 켜져 있는지 확인하고 입력창을 클릭하세요. 그래도 보이지 않으면 다시 찾기와 페이지 새로고침을 차례로 사용하세요.

Replace 버튼을 누를 수 없음

먼저 지원 AI 페이지에서 페이지에서 가져오기를 눌러 현재 입력창을 연결하세요. 가져온 뒤 페이지 내용을 직접 수정했다면 안전을 위해 연결이 해제되므로 다시 가져와야 합니다.

Extension context invalidated 오류

확장 프로그램을 업데이트한 뒤 기존 탭에 예전 스크립트가 남아 생깁니다. 확장 관리 화면과 AI 페이지를 각각 새로고침하세요. 오류 페이지에 남은 과거 기록은 휴지통 아이콘으로 지울 수 있습니다.

HTTP 404 또는 NOT_FOUND

저장된 Gemini 모델을 현재 키에서 사용할 수 없습니다. API 설정에서 사용 가능한 모델 조회를 누르고 목록에 표시된 생성 모델을 선택해 저장하세요. 키를 반복 발급할 필요는 없습니다.

HTTP 429 또는 RESOURCE_EXHAUSTED

무료 등급의 분당·일일 호출 또는 토큰 할당량에 도달했을 가능성이 큽니다. Google AI Studio에서 사용량을 확인하고 한도가 복구된 뒤 다시 시도하세요. 확장 프로그램은 유료 등급이나 다른 모델로 자동 전환하지 않습니다.

HTTP 401·403 또는 인증 오류

키가 잘못됐거나 프로젝트·모델 권한이 없는 상태입니다. API 설정에서 키를 삭제하고 올바른 Gemini API 키를 등록한 뒤 Chrome의 연결 권한을 허용하세요.

결과가 의도와 다름

원문에 반드시 지켜야 할 조건, 원하는 결과 형식, 제외할 내용을 구체적으로 추가하세요. 정확한 분석에는 Precision, 짧은 결과에는 ECO를 선택해 다시 최적화하세요. 결과는 적용 전에 항상 검토하세요.

DATA

API 키와 데이터

  • Optimize를 누를 때 원문과 선택 설정이 Gemini API로 전송됩니다.
  • 키는 기본적으로 브라우저 세션 동안만 보관됩니다. 영구 저장을 선택하면 현재 Chrome 프로필의 로컬 저장소에 저장됩니다.
  • 초안은 동기화 저장소에 올리지 않으며 Reset으로 바로 지울 수 있습니다.
  • 무료 등급 여부와 한도는 Google 프로젝트 상태에 따라 달라집니다.
