# Prompt Optimizer 1.9.0 홍보 자료

## 핵심 메시지

**생각은 그대로, 요청은 더 명확하게.**

평소 말하듯 작성한 요청을 Gemini가 목적·조건·출력 형식에 맞춰 분석하고, ChatGPT·Claude·Gemini·Perplexity에서 사용할 수 있는 프롬프트로 재작성합니다.

보조 문구:

- 복잡한 프롬프트 작성법을 외울 필요 없이 자연어로 시작하세요.
- 결과를 확인한 뒤 복사하거나 연결된 AI 입력창에 넣을 수 있습니다.
- 사용자가 직접 등록한 Gemini API 키를 사용하며 메시지를 자동 전송하지 않습니다.

다음 문구는 제공된 `Prompt Optimizer 1.9.0` 벤치마크 결과를 근거로 사용할 수 있습니다.

- 핵심 정보 문자열 보존율 **96.2%**
- 프롬프트 언어 정확도 **100%**
- 불필요한 서두 없이 시작한 비율 **100%**

- 요청당 평균 API 사용량 **529토큰**

항상 함께 표시할 각주:

> Prompt Optimizer 1.9.0의 내부 고정 시험 8건을 gemini-3.5-flash-lite로 2026년 10월 12일 측정한 결과입니다. 자동 품질 점수는 핵심 정보 보존, 의도 분류, 프롬프트 언어 및 출력 시작 형식을 조합한 내부 회귀 지표입니다. 모델·네트워크·할당량에 따라 결과가 달라질 수 있습니다.

보존율 96.2%의 누락 1건은 `3,500만원`이 결과에서 `3,500만 원`으로 띄어쓰기 된 것을 정확 문자열 불일치로 계산한 사례입니다. 의미상 금액은 유지되었습니다.

## Chrome 웹 스토어 문구

### 제품명

Prompt Optimizer – AI 프롬프트 최적화

### 짧은 설명

평소 말하듯 작성한 요청을 분석해 ChatGPT·Claude·Gemini·Perplexity용 프롬프트로 명확하게 재작성합니다.

### 상세 설명

Prompt Optimizer는 자연어 요청의 목적, 조건, 중요한 세부 정보와 원하는 결과 형식을 분석해 더 명확한 프롬프트로 재작성하는 Chrome 확장 프로그램입니다.

프롬프트 공식을 외우거나 매번 긴 템플릿을 복사할 필요가 없습니다. 평소처럼 요청을 작성하고 대상 AI, 응답 언어와 최적화 모드를 선택하면 됩니다.

주요 기능:

- Gemini 기반 의미 분석과 맞춤형 프롬프트 재작성
- ChatGPT, Claude, Gemini, Perplexity 대상별 설정
- 기본, ECO, Precision, Natural 최적화 모드
- 한국어·영어·일본어·중국어 요청 인식
- 원문 가져오기, 결과 복사 및 입력창 교체
- 움직이거나 잠시 숨길 수 있는 페이지 미니 도구
- 입력창 다시 찾기와 연결 복구
- 오류 진단 보고서와 정량 성능 평가

개인 Gemini API 키를 사용합니다. 최적화할 때 작성한 요청과 선택 설정이 Gemini API로 전송됩니다. 확장 프로그램은 메시지를 자동으로 전송하거나 유료 모델로 자동 전환하지 않습니다. 생성된 결과를 확인한 뒤 사용자가 직접 적용합니다.

### 스크린샷 캡션

1. 평소 쓰던 요청을 입력하고 대상 AI와 모드를 선택하세요.
2. Gemini가 요청의 의미와 조건을 분석해 맞춤 프롬프트로 재작성합니다.
3. 결과를 검토한 뒤 복사하거나 AI 입력창에 교체합니다.
4. 페이지 미니 도구로 입력창 옆에서 바로 최적화할 수 있습니다.
5. 내장 성능 평가로 모델과 버전별 품질·속도·토큰을 비교합니다.

## 소개 영상 또는 데모 순서

1. 모호한 요청 입력: “이 코드 왜 안 되는지 분석해줘.”
2. Precision 모드와 대상 AI 선택
3. Optimize 실행
4. 원인·확인 방법·수정 방법·성공 조건이 포함된 결과 강조
5. Copy 또는 Replace 사용
6. 입력창에는 들어가지만 자동 전송되지 않는 장면 표시
7. 성능 평가 화면에서 95.6점과 완료율 100% 표시

권장 길이: 25~35초.

## 표현 기준

사용 가능한 표현:

- “내부 고정 8개 테스트에서 완료율 100%”
- “핵심 정보 문자열 보존율 96.2%”
- “응답시간 중앙값 2.25초”
- “프롬프트를 적용하기 전에 사용자가 결과를 확인”

피해야 할 표현:

- “정확도 95.6%” — 품질 점수는 정답 정확도가 아닙니다.
- “항상 더 좋은 답변 보장” — 최종 답변 품질은 대상 AI와 입력에 따라 달라집니다.
- “업계 최고”, “가장 빠른” — 비교 대상이 없는 주장입니다.
- “완전 무료” — Gemini API 등급과 할당량에 따라 달라집니다.
- “개인정보가 전혀 전송되지 않음” — 최적화 요청은 사용자의 Gemini API로 전송됩니다.
