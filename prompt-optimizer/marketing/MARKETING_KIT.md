# 말결(Malgyeol) 홍보 자료 — 1.13.0

**내 뜻을 살리는 프롬프트.**

기존 Prompt Optimizer의 새 이름은 **말결**입니다. 스토어 표시명은 **말결 — AI 프롬프트 최적화**, 영문명은 **Malgyeol**을 사용합니다.

## 스토어 소개 · 복사용

말결은 평소 말하듯 작성한 요청의 목적과 조건을 분석해, 사용할 AI 모델에 맞는 프롬프트로 다듬는 Chrome 확장 프로그램입니다.

프롬프트 공식을 외우거나 매번 긴 템플릿을 복사할 필요가 없습니다. 평소처럼 요청을 작성하고 대상 AI, 세부 모델, 응답 언어와 최적화 모드를 선택하세요. 결과를 검토한 뒤 복사하거나 연결된 AI 입력창에 넣을 수 있습니다.

주요 기능:

- 개인 Gemini API 키를 이용한 의미 분석과 맞춤형 프롬프트 재작성
- ChatGPT / OpenAI, Claude, Gemini 브랜드별 세부 모델 선택과 모델명 검색
- 공식 문서 기반 지침과 출처 확인, 공개 모델 목록 갱신과 프로필 상태 표시
- Default · ECO · Precision · Natural · Custom 모드
- 여러 콘셉트를 조합하는 자동 Custom과 직접 지침을 작성하는 수동 Custom
- 최적화 전에 확인하는 API 키 등록·접근 권한 상태
- 한국어·영어·일본어·중국어 요청 인식
- 원문 가져오기, 결과 복사, 입력창 교체와 되돌리기
- 이동·숨김·작은 아이콘으로 최소화할 수 있는 페이지 미니 도구
- 입력창 다시 찾기, 사용 설명서와 오류 진단

사용자가 직접 등록한 Gemini API 키를 사용합니다. Optimize를 누르면 작성한 요청과 선택 설정이 Gemini API로 전송됩니다. Custom에서는 선택한 콘셉트 또는 직접 작성한 지침도 함께 전송됩니다. 무료·유료 여부와 사용 한도는 사용자의 Gemini API 프로젝트 설정에 따릅니다.

메시지를 자동으로 전송하거나 다른 유료 모델로 자동 전환하지 않습니다. 결과를 확인한 뒤 사용자가 직접 적용합니다. 대상 AI 선택은 프롬프트의 재작성 방향을 정하며, 웹 AI의 모델 자체를 자동으로 바꾸지 않습니다.

## 기존 성능 자료를 인용할 때

`evidence/benchmark-1.9.0.json`과 `assets/benchmark-card-1200x675.*`는 **이전 이름 Prompt Optimizer 1.9.0**의 역사적 측정 자료입니다. 최신 말결 1.13.0의 성능 측정치로 소개하지 않습니다.

해당 자료를 별도로 인용할 때에는 내부 고정 시험 8건, gemini-3.5-flash-lite, 2026-10-12 측정임을 함께 표기합니다. 완료율 100%, 자동 품질 점수 95.6/100, 핵심 정보 문자열 보존율 96.2%, 응답시간 중앙값 2.25초는 이 제한된 과거 시험에만 해당합니다. 자동 품질 점수는 정답 정확도가 아니며 최신 모델별 지침의 품질 향상률을 입증하지 않습니다.

새 홍보 이미지에는 이 수치를 넣지 않았습니다. ‘항상 더 좋은 답변’, ‘완전 무료’, ‘개인정보가 전혀 전송되지 않음’과 같은 표현도 사용하지 않습니다.
