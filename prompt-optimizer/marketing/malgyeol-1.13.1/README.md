# 말결 1.13.1 — 제공한 로고를 적용한 디자인

이름: **말결 — AI 프롬프트 최적화**

슬로건: **내 뜻을 살리는 프롬프트.**

`logo-original.png`는 사용자가 제공한 `말결 로고.png`의 원본 복사본입니다. 원본의 도형·색상·비율을 바꾸거나 AI로 다시 그리지 않았습니다. 아이콘과 홍보 자료에서는 Chrome으로 필요한 크기에 맞춰 표시했습니다. 로고의 짙은 초록색, 크림색과 유려한 선을 앱의 헤더·색상·곡선 장식에 반영했습니다.

이전 말풍선 아이콘과 종이 리본 디자인은 이 배포판에서 제거했습니다.

| 파일 | 크기 | 용도 |
| --- | --- | --- |
| `store-icon-128.png` | 128×128 | 스토어 아이콘 |
| `small-promo-440x280.png` | 440×280 | 작은 프로모션 타일 |
| `marquee-promo-1400x560.png` | 1400×560 | 마키 프로모션 타일 |
| `screenshot-01-workflow-1280x800.png` | 1280×800 | 요청 재작성 소개 |
| `screenshot-02-custom-1280x800.png` | 1280×800 | Custom 설정 소개 |
| `screenshot-03-models-1280x800.png` | 1280×800 | 세부 모델 선택 소개 |

스토어 PNG는 알파 채널 없는 24비트 RGB입니다. 소개 화면에는 실제 확장 HTML과 설명용 데이터를 사용했습니다. 실제 API 호출이나 성능 측정 결과가 아니며 이미지 하단에도 표시했습니다.

`source/*.html`은 편집 가능한 조판 원본입니다. 프로젝트 폴더에서 `node tools/render-brand-assets.mjs`로 전체 자료를 다시 만듭니다. 런타임 아이콘만 만들 때는 `python tools/generate-icons.py`를 실행합니다. Node 22 이상과 Chrome이 필요하며 `BROWSER_PATH` 환경 변수로 Chrome 경로를 지정할 수 있습니다. 이 과정은 유료 API를 호출하지 않습니다.
